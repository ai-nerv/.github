What holds the shape

Every one of these runs on the way to main. Each repository runs its own set, because each has its own way to go wrong; the last column says where.

And above the four, one more. The root repository builds all four from the pinned commits, runs every gate and every suite against the binaries it just built, then runs fifteen end-to-end scenarios against real processes and a scripted provider — on every push. It is how a change in one program that breaks another is caught before either is released.
